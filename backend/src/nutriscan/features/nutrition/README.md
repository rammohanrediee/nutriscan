# Nutrition module placeholder

Nutrition will calculate values deterministically from catalog-resolved foods and user-confirmed
portions after the model-selection gate passes. It must never accept vision output as nutrition.

Only the module's future public interface may be imported by another feature.

IFCT 2017 is being assessed as a candidate composition source. Its numeric tables are not imported
because product use requires written permission from ICMR-NIN. See
[`docs/research/ifct-2017-nutrition-data.md`](../../../../../docs/research/ifct-2017-nutrition-data.md)
for provenance, interpretation rules, and the future import contract.
